# Data

The datasets are public but are not redistributed here. Download them and place the CSV files in this folder:

| File | Source |
|---|---|
| `Crop_recommendation.csv` | Ingle, A.: Crop Recommendation Dataset, Kaggle : https://www.kaggle.com/datasets/atharvaingle/crop-recommendation-dataset |
| `yield_df.csv` | Patel, R.: Crop Yield Prediction Dataset: Predicting Crop Yield of 10 Most Consumed Crops in World, Kaggle : https://www.kaggle.com/datasets/patelris/crop-yield-prediction-dataset |

Expected shapes: `Crop_recommendation.csv` has 2,200 rows and 8 columns; `yield_df.csv` has 28,242 rows (13,130 after averaging duplicated country–crop–year rows).
